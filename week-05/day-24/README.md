# Неделя 5 — День 24. Цитаты, источники и анти-галлюцинации

## Задание

**Доработайте RAG так, чтобы модель обязательно возвращала:**
- ответ
- список источников (source + section/chunk_id)
- цитаты (фрагменты из найденных чанков)

**Проверьте на 10 вопросах:**
- есть ли источники в каждом ответе
- есть ли цитаты в каждом ответе
- совпадает ли смысл ответа с цитатами

**Усиление:**
- добавьте правило: если релевантность ниже порога — ассистент обязан сказать “не знаю” и попросить уточнение

**Результат:**
- Ответы с обязательными источниками и цитатами + режим “не знаю” при слабом контексте

## Реализация

### Новый файл: `ragger/answer.py`
- Модуль генерации структурированного ответа RAG с цитатами, источниками и анти-галлюцинациями
- `RagAnswer` dataclass: `query`, `answer`, `sources: list[dict]`, `confidence: str`
- `generate_answer()` — форматирует чанки с doc ID-разметкой (`<doc id="...">`), вызывает LLM с требованием вернуть JSON `{answer, sources, confidence}`
- При пустых чанках → `confidence="none"` (режим "не знаю")
- При ошибке LLM → fallback c `confidence="low"`
- Робастный парсинг JSON: 4 попытки (прямой → ```json → {answer...} → любой {})

### Модифицирован: `agents/jarvis.py` (RAG-блок, ~стр. 277-306)
- Вместо inline-промпта `"Используй следующие документы..."` теперь вызывается `generate_answer()`
- Result injected as system message с готовым ответом, источниками и цитатами
- Инструкция main LLM: сохранить источники и цитаты в финальном ответе
- При `confidence="none"` → инструкция сказать "не знаю"

## Сценарий проверки

1. **Отправь запрос:** `/rag` → ожидается список подкоманд
2. **Отправь запрос:** `/rag on` → RAG включён
3. **Вопрос из базы:** `Что такое RAG?` → ответ с источниками (source + chunk_id) и цитатами
4. **Вопрос из базы:** `Какие есть стратегии чанкинга?` → ответ с источниками и цитатами
5. **Вопрос вне базы:** `Сколько лет Юрию Гагарину?` → ответ "Я не знаю" без галлюцинаций
6. **Отправь запрос:** `/rag off` → RAG выключен
7. **Тот же вопрос без RAG:** `Что такое RAG?` → ответ без источников и цитат (из памяти модели)
8. **Отправь запрос:** `/rag on` → RAG включён обратно
9. **Финальный вопрос из базы:** любой из списка → ответ с источниками и цитатами
