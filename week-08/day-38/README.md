# Неделя 8 — День 37. Testing

## Задание

Подготовьте два уровня тестирования:
👉 Уровень 1 — код: unit/integration тесты на бизнес-логику 
👉 Уровень 2 — UI: smoke-сценарии, которые агент прогоняет сам через Playwright MCP / Claude in Mobile

Уровень 1. Автотесты на код:
👉 дайте ассистенту промпт: он сам находит непокрытые модули, пишет тесты, запускает, убеждается что проходят 
👉 минимум 3 файла, тесты должны пройти с первого запуска

Уровень 2. Smoke через MCP:
👉 опишите 3–5 пользовательских сценариев текстом (логин → создать сущность → проверить что появилась → удалить) 
👉 агент берёт сценарий и сам протыкивает UI: открывает страницы, кликает кнопки, заполняет формы, проверяет результат 
👉 используйте Playwright MCP (веб) или Claude in Mobile (мобилка) 
👉 агент сам фиксирует: прошёл сценарий или нет, скриншот на каждом шаге, что сломалось

Добейтесь полного цикла:
👉 агент пишет код-тесты → прогоняет → формирует отчёт 
👉 агент берёт smoke-сценарии → протыкивает UI через MCP → формирует отчёт со скриншотами 
👉 если что-то упало — агент предлагает в каком месте проблема

Усиление:
👉 встройте оба уровня в flow: после PR агент прогоняет код-тесты и smoke-сценарии, собирает единый отчёт 
👉 добавьте сценарий: "я задеплоил новую фичу — обнови smoke-сценарии и прогони всё заново"

Результат:
Код-тесты на 3+ модуля + 3–5 smoke-сценариев, которые агент прогоняет через MCP сам + отчёт со скриншотами + интеграция в flow разработки
