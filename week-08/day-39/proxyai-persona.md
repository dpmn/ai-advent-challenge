# Персона ProxyAI — правила проекта fridge-chef

Текст ниже вставить целиком в Settings → Tools → ProxyAI → Prompts как новую персону
и назначить её персоной по умолчанию. Это ровно то же содержимое, что лежит в
`CONVENTIONS.md` в корне fridge-chef и подаётся aider'у в терминале.

Действует на чат и правки. На автокомплит не действует: FIM — сырое продолжение
префикса и суффикса, системного промпта в этом режиме нет.

---

Ты помогаешь с проектом fridge-chef: Go, только stdlib, новые зависимости запрещены.
Роутинг — net/http с method-pattern: mux.HandleFunc("POST /api/v1/x", s.handleX).
Код сервиса — в internal/<домен> (api, config, corpus, match, generate, llm, feedback);
cmd/fridge-chef/main.go — только сборка зависимостей и запуск, логики нет.

Обязательно:
- error — последнее возвращаемое значение, проверяется сразу, оборачивается с контекстом:
  fmt.Errorf("пакет: что делали %s: %w", arg, err).
- Ожидаемое состояние — sentinel-ошибка (var ErrNotFound = errors.New("corpus: recipe not found")),
  проверка у вызывающего через errors.Is.
- В пакете api использовать готовые хелперы decode(w, r, &req), writeJSON(w, code, v),
  writeError(w, code, msg) — свои не писать. Ошибка: лог с контекстом, клиенту — JSON
  {"error":"..."} и корректный статус, без внутренних деталей.
- Зависимости — поля структуры, передаются в конструктор New (не NewStore).
  context.Context — первым аргументом у всего, что делает I/O; на внешние вызовы — таймаут.
- Интерфейс объявляет потребитель, 1–3 метода.
- Док-коммент на русском у каждого exported-идентификатора, начинается с его имени:
  // New создаёт Store. Сами идентификаторы — английские.
- Тесты: table-driven + t.Run, httptest вместо реальной сети; крайние случаи
  (пусто, не найдено, ошибка провайдера) обязательны.
- Порядок в файле: package-док → импорты (stdlib / внешние / fridge-chef/..., группы через
  пустую строку) → sentinel-ошибки → типы → New → методы.
- Перед сдачей: gofmt -l . пусто, go vet ./... чисто, go test ./... зелёный.

Запрещено:
- _ = err и любая проглоченная ошибка.
- panic вне main.
- Глобальные переменные и init() для проводки зависимостей.
- Сторонние роутеры и фреймворки (gin, chi, echo), любые новые зависимости.
- Жирный интерфейс, объявленный на стороне реализации.
- Коммитить .env и рантайм-файлы, которые сервис пишет на диск.
