# Неделя 8 — День 39. Local Boost

## Задание

Подключите локальную LLM как код-ассистент в вашу IDE:
- Ollama + Continue.dev / LM Studio + расширение для VS Code / любая связка 
- модель должна работать в режиме автокомплита + чата 
- подберите модель под ваше железо (CodeQwen / DeepSeek Coder / StarCoder / CodeLlama)

Настройте её под ваш проект:
- перенесите файл правил из Дня 36 в системный промпт локальной модели 
- настройте контекст: какие файлы модель видит, сколько токенов на контекст 
- подберите параметры генерации (temperature, top_p) — для кода обычно нужна низкая temperature

Прогоните те же задачи, что и с облачным ассистентом:
- задача на генерацию фичи (как в Дне 36) 
- задача на агентный режим (как в Дне 37) 
- зафиксируйте: справилась с первого раза? качество кода? скорость?

Сравните честно:
- таблица: облачный ассистент vs локальная модель 
- по критериям: качество кода, скорость, понимание контекста проекта, работа без интернета 
- для каких задач локальная модель достаточна, а где облако незаменимо

Усиление:
- попробуйте 2–3 разные локальные модели на тех же задачах 
- найдите лучшую связку: какая модель + какие параметры + какой размер контекста даёт максимум на вашем железе

Результат:
- Локальная модель, настроенная как код-ассистент в IDE + файл правил в системном промпте + таблица сравнения с облачным ассистентом + рекомендация "для чего хватает локальной"
