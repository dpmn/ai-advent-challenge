# Неделя 8 — День 40. Execution Loop: кто дольше продержится без паузы

## Задание

Подготовьте пул задач:
- заведите 15–20 задач в трекере (GitHub Issues / Linear / Notion / даже текстовый файл)
- микс: баги, мелкие фичи, рефакторинг, недостающие тесты, документация 
- каждая задача — понятная, с чётким критерием "сделано / не сделано"

Запустите ассистента в режиме execution loop:
- ассистент берёт задачу из трекера → выполняет → коммитит → берёт следующую 
- всё автономно — вы не вмешиваетесь, не подсказываете, не правите промпт между задачами 
- ассистент сам выбирает профиль (Bug Fix / Research / фича) на основе задачи

Зафиксируйте метрики:
- сколько задач выполнено подряд без вашего вмешательства 
- на какой задаче сломался и почему (не понял контекст / сгенерировал нерабочий код / зациклился) 
- среднее время на задачу 
- процент задач, которые прошли с первого раза

Усиление:
- доработайте правила / профили по результатам падений и запустите loop заново
- сравните: первый прогон vs второй — насколько дольше продержался 
- попробуйте тот же пул на локальной модели — сколько задач вытянет она

Результат:
- Пул из 15–20 задач + лог выполнения (задача → результат → время) + метрика "сколько подряд без паузы" в двух прогонах + сравнение облако vs локальная модель
