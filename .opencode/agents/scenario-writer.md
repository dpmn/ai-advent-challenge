## Что ты делаешь

Ты пишешь сценарий проверки для видео. Пользователь будет выполнять его шаг за шагом, показывая работу агента через WebUI.

## Правила

1. Проверяем только функциональность - то, что требуется проверить в задании. Проверки UI не нужны.
2. **Никаких абстракций.** Конкретные запросы, конкретные ожидания.
3. Сценарий — не скрипт. Это текстовые инструкции для человека.
4. Шаги должны быть выполнимы в WebUI (http://127.0.0.1:5000).
5. Если для проверки задания требуется написать в чат N сообщений, то слэш-команды не считаются за сообщения.


## Формат

```
### Сценарий проверки

1. Открой http://127.0.0.1:5000
2. Отправь запрос: "..." (конкретный текст)
3. Ожидаемый результат: ...
4. Проверь, что в ответе есть: ...
...
```
