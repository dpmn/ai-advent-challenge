# AI Advent Challenge — конфиг проекта

## О проекте

Рабочий журнал курса-челленджа AI Advent Challenge #8 — научиться быстро использовать инструменты ИИ.
Здесь код заданий, конспекты лекций и прогресс прохождения. Принцип курса: всё делаем через ИИ, код руками не пишем.

## Команды

- Запуск WebUI: `python3 ./webui/app.py` → открыть http://127.0.0.1:5000
- Проверка задания: через браузер (http://127.0.0.1:5000) или `curl`. Проверяем функциональность, не UI.

## Структура проекта

```text
/
├─ agents/              # Ядро агента JarvisAgent и его модули (mixin-файлы, FSM, инварианты, MCP-клиент)
├─ docent/              # Портабельный CLI-ассистент (pip/uv-пакет): RAG по докам репо + git-контекст через MCP (stdio)
├─ mcp_servers/         # MCP-серверы (FastMCP, streamable-http): nasa, space_monitor, composer, ragger
├─ ragger/              # RAG-пайплайн: chunking, эмбеддинги, FAISS, reranker, answer с цитатами, нативный Ollama-клиент
├─ webui/               # Flask + SPA (vanilla JS), Claude-inspired тема + light/dark toggle
├─ docs/                # Документация, конспекты лекций (lessions/), прогресс, database-schema
├─ week-NN/             # Задания по дням (day-NN/README.md)
├─ .github/             # GitHub Actions (ai-review.yml — реактивное AI-ревью PR через docent)
└─ .claude/
   ├─ agents/           # Субагенты: task-initializer, docs-sync
   ├─ skills/           # Модули знаний: backend-rules, webui-rules
   └─ commands/         # Слэш-команды: /day
```

## Окружение и API

- ОС: Linux, shell bash. Используй `python3` и Unix-пути (`./webui/app.py`).
- Стек: Python 3.12, Flask.
- API для кода заданий: **Cloud.ru, сервис Foundation Models** (оплата в рублях, OpenAI-совместимый доступ).
  - Спецификация: https://cloud.ru/docs/foundation-models/ug/topics/api-ref__specs
  - base_url: `https://foundation-models.api.cloud.ru/v1`
  - Auth: заголовок `Authorization: Bearer <CLOUDRU_SECRET_KEY>`
  - Ключ: в `.env` как `CLOUDRU_SECRET_KEY` (НЕ коммитить, см. `.gitignore`).
- ID моделей:
  - `Qwen/Qwen3-30B-A3B` — базовая (дёшево), для простых задач
  - `Qwen/Qwen3-Coder-Next` — для задач средней сложности
  - `MiniMaxAI/MiniMax-M2.5` — для тяжёлых задач
  - `openai/text-embedding-3-small` — для эмбеддингов

## Стиль кода

- Все публичные классы, методы и функции документируй **docstring**. Исключение — тривиальные однострочные геттеры/сеттеры.
  ```python
  def chat(self, user_input: str) -> str:
      """Принимает запрос пользователя, возвращает ответ агента."""
  ```
- Внутренние/приватные методы (`_*`) — docstring по необходимости, если логика неочевидна.
- Детальные конвенции по бэкенду — в skill `backend-rules`, по интерфейсу — в skill `webui-rules`.

## Git / безопасность

- Ничего не пушить в интернет без явного разрешения. Удалённый репозиторий создаёт пользователь сам.
- `.env`, `*.key` и секреты — никогда не коммитить.

## Рабочий процесс дня

При новом задании создаётся `week-XX/day-YY/README.md` с сутью задания. Затем — команда **`/day`**:
она оркеструет весь дневной цикл (контекст → обсуждение → план → реализация → сценарий → пауза на видео → выводы → синхронизация доков),
диспетчеризуя субагенты `task-initializer` и `docs-sync` через Agent tool.

## Фазы работы (всегда)

Три фазы с явными воротами. За ворота — только после моей отмашки.

1. **Обсуждение.** Разбираем задание/теорию: что делаем, зачем. Уточняем вопросами. **Никакого кода, никакого плана.**
2. **Планирование.** Только после отмашки. План: какие файлы, что меняем, порядок. Вопросы, корректировки. **Всё ещё никакого кода.**
3. **Реализация.** Только после явной отмашки («давай делай», «реализуй», «погнали» и т.п.).

**Не пиши и не редактируй код, пока я явно не разрешил перейти к реализации.** Не уверен, какая фаза сейчас — спроси.
