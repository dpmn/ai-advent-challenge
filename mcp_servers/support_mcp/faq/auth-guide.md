# TaskFlow — гайд по авторизации и токенам

## Способы входа

TaskFlow поддерживает три способа входа: email + пароль, вход через Google,
SSO по SAML 2.0 (только на тарифе Business). Способ входа привязан к аккаунту:
если вы регистрировались через Google, вход по паролю недоступен, пока вы
не зададите пароль в «Настройки → Безопасность».

## Сессии

Сессия живёт 30 дней с момента последней активности. Все активные сессии видны
в «Настройки → Безопасность → Активные сессии», любую можно завершить удалённо.
Смена пароля завершает все сессии сразу.

## Персональные API-токены

Токены создаются в «Настройки → API-токены». Токен показывается один раз при
создании. У токена есть скоупы: read, write, admin. Токены отзываются:

- вручную владельцем;
- автоматически при смене пароля владельца;
- автоматически при отключении пользователя из команды.

Запрос с отозванным токеном возвращает 403 Forbidden с телом
{"error": "token_revoked"}.

## Коды ошибок авторизации

- 401 Unauthorized — токен не передан или неверный формат заголовка.
  Правильный формат: Authorization: Bearer tf_xxxxx.
- 403 token_revoked — токен отозван (смена пароля, удаление из команды).
- 403 insufficient_scope — у токена нет нужного скоупа (например, write).
- 429 rate_limited — превышен лимит запросов тарифа.

## SSO (Business)

При включённом SSO вход по паролю для участников команды отключается,
кроме владельца (аварийный доступ). Провижининг пользователей — SCIM 2.0.
