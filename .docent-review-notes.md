# Осознанные решения проекта (для AI-ревью)

Эти решения приняты намеренно. **Не репорти их как баги или проблемы** —
они здесь, чтобы гасить повторные находки.

## docent (ассистент/ревьюер)

- **Лимиты и `code_globs` конфигурируемы.** `max_diff_chars`, `max_file_chars`,
  `max_context_files`, `code_globs`, `fallback_model` — поля `Config`,
  переопределяются через `.docent/config.json`. Значения по умолчанию заданы
  под этот репозиторий намеренно. Не флагать «захардкожено».
- **Удалённые/отсутствующие файлы в контекст не читаем.** `_read_changed_files`
  пропускает файлы, которых нет в working tree, — это намеренно (в Action и
  локальном `git diff` изменённые файлы всегда на диске).
- **`chunk_python` не заходит в тела функций.** class/def, объявленные внутри
  функции, не индексируются — известное и принятое ограничение (редкий кейс).
- **Маркеры усечения намеренные.** `[... усечено N строк ...]` /
  `[... файл усечён ...]` — сознательный сигнал модели о неполном контексте.
- **SOURCES-маркер парсится только на последней строке ответа** — намеренно,
  чтобы упоминание «SOURCES» в теле не ловилось.
- **Ключ читается из `DOCENT_API_KEY`** (провайдер-нейтрально), а не из
  `CLOUDRU_SECRET_KEY`. Так задумано.
