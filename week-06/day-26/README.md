# Неделя 6 — День 26. Запуск локальной LLM

## Задание

Установите и запустите любую локальную LLM (Ollama, LM Studio, llama.cpp, Mistral, Qwen, Phi и т.п.)

**Проверьте:**
- модель запускается локально
- к ней можно обратиться через CLI или HTTP API
- модель отвечает на простой запрос

**Сделайте:**
- минимум 3 запроса разной сложности

**Результат:**
- Локальная LLM запущена и отвечает на запросы

## Вопросы для проверки

**Простой:**

```text
Сколько будет 17 × 24?
```

```text
Столица Австралии?
```

**Средний:**

```text
Напиши функцию на Python, которая проверяет, является ли строка палиндромом, без учёта пробелов и регистра
```

```text
У Пети было 5 яблок, он отдал 2 Маше и купил ещё 7. Сколько яблок у Пети?
```

**Сложный:**

```text
Объясни разницу между рекурсией и итерацией, приведи пример, где рекурсия явно хуже по производительности
```

```text
Верни JSON с полями name, age, skills для персонажа-программиста — без пояснений, только валидный JSON
```

## Результаты проверки

**Модель:** `qwen2.5-coder:7b` через Ollama, CLI (`ollama run qwen2.5-coder:7b`)

| Вопрос | Результат |
|---|---|
| 17 × 24 | 408 — верно |
| Столица Австралии | Канберра — верно |
| Яблоки Пети (5 - 2 + 7) | 10 — верно |
| Палиндром на Python | Рабочая функция, корректно объяснена логика |
| JSON name/age/skills | Валидный JSON без лишних пояснений |
| Рекурсия vs итерация | Развёрнутое объяснение с примером (факториал), код для обоих подходов |

### Выводы

- Модель запускается локально и отвечает через CLI (`ollama run`), Ollama также поднимает HTTP API на `localhost:11434`
- Простые и средние запросы (арифметика, факты, генерация кода) — без ошибок
- Инструкция «без пояснений, только валидный JSON» соблюдена буквально — модель не добавила лишний текст
- Сложный запрос (рекурсия vs итерация) обработан корректно, с адекватным примером и рабочим кодом для обоих вариантов
